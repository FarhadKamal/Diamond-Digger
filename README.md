💎 Diamond Digger
⛏️ Find the hidden diamond in the 8×13 grid with only 5 attempts!

🎮 Play the Game
Play Diamond Digger Here

🕹️ How to Play
Click on any cell in the 8×13 grid to dig

You have only 5 digs to find the hidden diamond

Each wrong dig reveals a directional hint (North, South, East, West)

Use the hints wisely to locate the diamond before your digs run out!

✨ Features
Beautiful golden ratio design (13:8 grid for perfect proportions)

Directional hints that guide you to the diamond

Smooth animations and visual effects

Mobile-responsive design

No scrolling required - fits perfectly on any screen

Mysterious atmosphere with glowing effects

🎯 Game Rules
Find the diamond within 5 digs to win

Each wrong dig reduces your remaining attempts

Directional indicators light up to show the hint

Game ends when you find the diamond or run out of digs

🎨 Design Notes
The game uses the golden ratio (1.618:1) for its 13×8 grid layout, creating a visually pleasing and mathematically harmonious experience. All animations and effects are optimized to prevent layout shifts.
